## 0.1.14 播放页文案字号

根据 FLEX 1791895069，剧名位于 SSShortVideoOutterSeriesLeftContainerView 的标题 UILabel，集数简介使用 YYLabel，展开文字为同容器中的 UILabel。新增播放页文案总开关和独立的剧名、集数简介/展开字号比例（55%–100%），默认原字号。涵盖首页与合集的对应左侧信息容器，保持原生 frame/bounds 与入口布局。

底栏新方案仍需选择背景显示高度还是页面占位高度；两者影响不同。合集右侧位置修复已包含，底栏高度修改暂不自动恢复。

## 0.1.13 合集播放右侧位置修复

FLEX 1791876865 显示右侧容器高 342 pt，而评论和点赞已经排到 y=394.6、528.8，超出容器。之前位移使用缓存原生 frame 的中心，无法覆盖宿主直接更新 center/bounds 的情况。

改为按当前实际 center/bounds 计算原生矩形和位移，每次约束更新后都重新锚定，不累计旧偏移。水平中心固定在右侧容器中间；隐藏控件恢复原始变换并不占排列空间。头像排列高度考虑可见关注角标（原生 46 pt 控件内角标可延伸到 50 pt），避免与收藏重叠。布局末尾观察者只安装一次。

合集专项测试包括四按钮加头像、隐藏分享、连续六次直接写 center/bounds、再次晚更新、容器内位置、水平居中与原生点击。底栏高度与视频投影继续停用。

## 0.1.12 关闭底栏高度功能

从构建中移除原生底栏的 frame/layout、位置重算、黑色背景底层、启动时底栏高度应用及相关生命周期 hooks。删除高度、悬浮和模糊偏好读取与设置入口；旧保存高度不再生效。底栏大小、位置、背景和原生按钮区域由红果处理，只保留底栏文字字号功能。

视频投影继续停用，右侧控件、顶部文字设置保留，布局保护保持停用。模拟器检查原生底栏 frame/layout 方法没有被 hook、旧 66 pt 设置不改变宿主 84 pt 高度、没有附加黑色图层以及视频和文案保持原生。

## 0.1.11 撤回视频列表投影

FLEX 1791870094 截图显示全集入口下方出现单独的视频带。列表整体投影与固定位置的入口叠层组合产生了画面断层；此前模拟器几何检查未覆盖真实宿主完整叠层。

撤回视频填充和控制层反向补偿，相关源码移入 experimental，不参与构建或安装。保持原生渲染、裁切、分页与文案位置；保留冷启动自动应用底栏高度、灰底高度和控件设置。视频与底栏之间的原生预留空隙暂时保留，避免用整个分页列表投影填充。

## 0.1.10 冷启动应用与间隙视频填充

按用户选择，底栏保持贴底，通过视频表面等比投影填满视频原下沿与底栏上沿之间的间隙。会轻微裁切左右边缘；保持 UICollectionView bounds、分页属性、contentSize、offset 以及播放器几何，控制层作反向投影补偿，尽量保持剧名、简介、全集入口与操作控件原显示位置。黑色底层不再覆盖扩展区域。

进入窗口、首次安装 hooks、延迟模块安装和回到前台时主动刷新保存的高度，不依赖切换侧边栏。测试包含冷启动保存 66 pt、视频渲染下沿、控制层文字显示位置和关闭时恢复。实际 Metal 视频和宿主手势仍需真机验证。

## 0.1.9 灰色背景高度调节

新增“灰色底栏高度”62–84 pt，调整首页/剧场/我的这一栏的整个背景（包括底部安全区），替代只标注按钮区的高度调节。

底栏缩小时，原预留区域可能继续露出同色页面底色，导致灰块看起来没有缩小。本版在底栏下方加入无交互的黑色图层，范围只覆盖宿主原始底栏预留区域；灰色背景随底栏实际高度缩小，露出区域显示黑色。底栏隐藏或透明时此图层同步隐藏，关闭增强时删除。

不移动全集入口、剧名或简介，也不改变视频布局和分页。缩小灰底不会扩展视频区域，原有空间仍保留，避免内容重排。布局保护保持停用，文字大小仍可调。

## 0.1.8 恢复原生底栏

停止悬浮、模糊层和底部背景清理。保留宿主全宽贴底样式、背景图片与灰色底色，移除 CYLTabBar、全集分发入口及控制器背景处理和自定义底栏点击映射。播放器、分页、全集入口、剧名与简介均不作布局调整。

底栏按钮区高度可调 28–50 pt，底部安全区另计，且不超过宿主原有预留区域；原始底栏底边保持不动，因此调大不会向视频和文案侵入。底栏字号和顶部字号继续可调，布局保护保持停用。旧版悬浮与模糊偏好不会再起作用。

新 FLEX 中存在标题子视图 y=110、父容器高度 80 的越界状态；静态树无法确认写入来源，本版撤销所有与文案背景有关的处理，并验证高度变化不会写入标题、简介或视频几何。真实红果文案是否恢复仍需设备确认。

## 0.1.7 深色模糊与返回布局修复

底栏改用公开的 UIBlurEffectStyleSystemUltraThinMaterialDark，固定深色外观，避免系统玻璃在当前配色下呈现白色。新增模糊层不透明度 20%–100% 与底栏文字大小 55%–120%；顶部文字大小继续可调。不透明度不等同于可指定像素半径的高斯模糊参数。

右侧布局不再每轮先还原 transform 再应用。宿主重复设置同一原始 frame 时跳过写入（使用浮点容差）；宿主自己的右侧布局回调读取原始几何，UIKit 的正常绘制和坐标转换仍使用真实缩放。这减少反复校正。布局保护保持停用。

模拟器夹具加入宿主核对 frame 并再次请求布局的场景、底栏真实 blur 类型、固定深色外观与字号重复设置；真机卡顿根因仍需设备堆栈确认，FLEX 静态树不能提供线程阻塞调用栈。

## 0.1.6 原生点击坐标修复

按用户要求暂时停用布局次数保护；历史记录保留，总开关仍可手动关闭。

0.1.5 只移动 sublayer 像素，宿主触摸或手势仍可能按原生位置判断。0.1.6 使用控件整体 UIView.transform 进行缩放与位移，由 UIKit 统一转换显示、手势和 UIControl 坐标。宿主布局及 setFrame 前恢复原始 transform，防止缩放影响宿主 frame 的尺寸计算；每轮更新结束后重新统一应用。

模拟器夹具加入原生 UIButton、真实窗口点转换与原生 target-action 检查；不能替代红果真实手势和按钮验证。播放器与分页处理不变。

## 0.1.5 首次显示与底部背景修复

右侧控件保留原生 frame、bounds 和 UIView.transform，通过图层缩放与位移排列像素。间距按缩放后的高度计算，0 pt 表示不增加空隙。进入窗口时注册，在主线程每轮更新结束前统一处理全部右侧控件，覆盖宿主晚于布局回调的重设；点击按显示位置映射回原生控件。

底部全集入口及其插入容器保持透明，隐藏其嵌套宽幅背景图片与磨砂层，保留入口图标、文字和交互。该清理跟随总开关；底栏所在控制器的底色在悬浮模式下清除。关闭增强恢复捕获的状态。

模拟器夹具加入首次显示、宿主晚重设全部控件、紧凑排列点击和底部嵌套背景恢复场景；仍需红果真机验证。

## 功能

- 设置 → **hgkiller**：独立入口卡片位于「红果净化」上方，不修改原列表的数据源、行号或点击回调。
- 头像、收藏、评论、点赞、分享独立显示开关。
- 右侧控件大小 55%–100%，默认 80%；隐藏项自动收紧排列；使用子图层视觉缩放，保留原来的点击视图尺寸。
- 底栏高度可调 44–80 pt，默认 54 pt；三个文字按等分槽位居中。
- 清除宿主旧磨砂层、背景图片和分割线，避免残留灰条。
- 悬浮液态玻璃底栏：使用系统公开 UIGlassEffect API；不可用时回退为系统磨砂材质。
- 保留宿主原有 Tab 控件及其点击动作，不创建平行的 Tab 控制器。
- 视频列表、Cell 与播放器容器延伸到底部；同步分页尺寸与页码，保留进度条。
- 高比例竖屏视频可裁切铺满，横屏及低比例竖屏保持比例。
- 顶部分类与搜索文字缩小，默认 85%，可调为 55%–100%。
- 总开关与恢复默认设置；所有偏好键使用 HGK.v1. 前缀。

## 构建与下载

GitHub Actions 自动运行几何测试、编译 arm64 iOS 动态库、进行 ad-hoc 签名并上传 artifact。
在仓库的 **Actions → Build hgkiller dylib → 成功的运行 → Artifacts** 下载 hgkiller-dylib 压缩包。

macOS 安装 Xcode 后运行：

    bash scripts/build.sh

输出：

    build/hgkiller.dylib
    build/SHA256SUMS.txt

最低部署版本为 iOS 14。源码通过运行时检测系统液态玻璃类，不要求本地 SDK 包含 iOS 26 头文件。
使用 Objective-C Runtime 的目标类方法拦截，无 CydiaSubstrate、Substitute 或 libhooker 依赖。
动态库仅在 com.phoenix.video 进程内启用。

注入工具需将 dylib 加载到宿主进程，并按其流程重新签名应用。构建产物的 ad-hoc 签名不等于任意设备上的安装授权。
本项目不修改宿主安装包、不提供应用 IPA。

## 当前验证范围

自动验证覆盖安全区底栏位置、可调高度、按钮等分、视频比例、竖屏裁切与扩展前后的页码对齐。
CI 另外运行 UIKit 模拟器回归测试：模拟宿主迟写按钮 frame、旧背景覆盖、连续改变缩放、非 FlowLayout 分页与关闭恢复。测试使用自建宿主夹具，不能替代真实红果注入验证。
iOS 编译通过仅证明源码可编译和动态库可生成；**未完成真机注入、截图与交互验收**。

全屏扩展只作用于首页视频流。运行时确认单 section、等高、纵向、整页单列布局后，适配分页属性与 content size，包含非 FlowLayout 的宿主布局。
不满足上述条件的布局保持宿主行为；不替换宿主 collection view layout 实例。
搜索详情、横屏窗口和画中画窗口不应用该布局方案。

与「红果净化」的入口和偏好设置独立；若另一插件也改同一控件的 frame、transform 或 hidden，
最终效果取决于双方 Hook 的执行顺序，仍需共同注入验收。关闭该插件中的重叠布局功能可减少争用。

## 真机验收

1. 设置页确认 hgkiller 在红果净化上方，两个入口都可打开。
2. 分别关闭右侧五个控件，确认重排、点击动作及重新开启正确。
3. 缩放拖至 55%、80%、100%，反复切换，确认无累计缩小。
4. Tab 的首页、剧场、我的切换正常，底栏不遮挡进度条的拖动。
5. 连续上下滑动视频，确认每页停靠准确；比较横屏和竖屏视频。
6. 关闭总开关和视频延伸开关，确认恢复布局。
7. 打开评论、选集、搜索，前后台切换及屏幕旋转，确认无错误铺满。

- src/HGEntry.m：Bundle 过滤、主线程初始化和延迟类加载重试。
